# Screenshot Guide

Add portfolio-ready screenshots for the README to this folder.

## Required screenshots

- `01-home.png` - main/home screen
- `02-schedule.png` - schedule/timetable screen
- `03-offline-state.png` - offline or cached-data state
- `04-settings.png` - settings screen
- `05-ocr-captcha.png` - login/captcha OCR flow
- `06-notification.png` - lesson notification example

## Optional screenshots

- `07-auth.png` - auth or registration flow
- `08-performance.png` - academic performance screen

## Recommendations

- Format: `PNG`
- Orientation: portrait
- Recommended device size: a 6.1-6.7" Android emulator, such as Pixel 6 / Pixel 7 / Pixel 8
- Recommended width: keep screenshots consistent across all files
- Use the exact file names above so README links work without changes

## Privacy and safety

- Do not show real logins, passwords, tokens, or session data
- Do not show real names, personal IDs, grades, or private account details unless they are fully anonymized
- Prefer demo or test data when possible
- Double-check notifications, profile screens, and auth screens before publishing images
